* Time complexity - How many operations of computer performed it measures time number of operations not time

* n - It represents to input size

1: O(1)-Constant Time
--same work every time 

2: O(log n)-logarithmic Time
--Divide by 2 each step

3: O(n)-Linear Time
--Visit every element once

4: O(n log n)-linera+logarithmic
--Visit every element + divide/ search 

5: O(n²)- Quadratic Time
--Mostly about Nested loop

6 O(2^n)- Exponential Time 
--Each step double the work

7: O(n!)- Factorial Time 
--Generates every possible arrangement

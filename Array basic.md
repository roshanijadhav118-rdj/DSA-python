* In python list[] is considered as array
* array - collection of data together
* It is ordered and mutable
* left to right indexing -[0,1, 2, 3.....]
* right to left indexing -[....-3, -2, -1]

Important built-in functions :
1) append()- add value at last index
2) insert()- add value at specific index
3) remove()- Remove by value
4) pop()- remove by index no.

Time complexity :
1) Update -O()
2) insert -O(n)
3) append -O(1)
4) remove -O(n)
